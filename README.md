# Baratu

## Descrição

O Baratu é uma plataforma voltada à divulgação de brechós e ao incentivo da moda sustentável e da economia circular.

O projeto foi desenvolvido utilizando HTML e CSS e tem como objetivo apresentar informações sobre o projeto, seus autores e sua proposta de promover o consumo consciente.

## Tecnologias Utilizadas

- HTML5
- CSS3
- GitHub
- Render

## Melhorias Implementadas

Durante a evolução do sistema foram realizadas as seguintes melhorias:

- Correção da navegação entre páginas.
- Correção da exibição da logo.
- Organização dos arquivos de imagem.
- Atualização da página inicial.
- Inclusão de conteúdo visual para apresentação do projeto.
- Publicação da aplicação em ambiente cloud utilizando o Render.

## Como Executar

1. Faça o download do projeto.
2. Abra o arquivo index.html em um navegador.

## Deploy

A aplicação está publicada na plataforma Render.

## CI/CD

O repositório está integrado ao GitHub. As alterações realizadas no projeto são versionadas e armazenadas no repositório remoto.
