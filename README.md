Projeto Prático - Deploy em Cloud com GitHub e CI/CD
Descrição
Este projeto consiste em um site desenvolvido utilizando HTML, CSS e JavaScript.

Tecnologias Utilizadas
HTML5
CSS3
JavaScript
GitHub
Vercel
Como executar
Faça o download do projeto.
Abra o arquivo index.html em um navegador.
Deploy
O projeto está hospedado na plataforma Vercel.

CI/CD
O GitHub está integrado ao Vercel. Toda alteração enviada para o repositório gera automaticamente uma nova implantação da aplicação.
